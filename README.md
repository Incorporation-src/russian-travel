# Путешествия по России
Данный проект представляет из себя интерактивную web-страницу о путешествиях по России. На странице представлена информация об одних из самых популяхных культурный и природных объектах,
а также о туризме.

## Содержание
- Заглавная часть страницы: заголовок и подзаголовок страницы.
- Вступительная часть страницы: статистика и информация о туристических мест России.
- Фотогалерея: на этой части страницы изображены различные пейзажи туристических мест России.
- Статьи и местах: подробная информация о таких местах как: Куршская коса, Кольский полуостров, Алтай, зимний Байкал и Карелия.
- Ссылки на полезные ресурсы: дополнительная информация о местах и маршрутах.
- Подвальная часть страницы: полезные ссылки на карты, прогноз погоды и т.п.

## Технологии
- HTML: разметка страниц.
- CSS: стили для дизайна и оформления.
- Ссылки: встроенные URL для получения дополнительной информации.
